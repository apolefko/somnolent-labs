---
title: Posting From Anywhere
date: 2026-04-30
---

No more Hugo. No more needing the original machine.

To add a new post, go to [github.com/apolefko/somnolent-labs](https://github.com/apolefko/somnolent-labs), navigate to the `md/` folder, click **Add file → Create new file**, and name it `YYYY-MM-DD-your-title.md`.

Add this at the top:

```
---
title: Your Post Title
date: YYYY-MM-DD
---
```

Then write in markdown below it. Commit to main and it's live in seconds.

That's the whole workflow.
